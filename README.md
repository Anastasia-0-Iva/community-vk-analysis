# VK Community Analyzer

VK Community Analyzer — это скрипт на Python, предназначенный для автоматического анализа сообществ ВКонтакте через API. Проект позволяет получать детальную информацию о подписчиках групп и проводить демографический, географический и статистический анализ аудитории.

## Основные возможности
Проект позволяет выполнять следующие задачи:

- **Получение данных о подписчиках**: Извлечение полного списка участников сообщества ВКонтакте
- **Демографический анализ**: Распределение подписчиков по полу и возрастным группам
- **Географический анализ**: Определение топ-городов проживания аудитории
- **Сбор детальной информации**: Для каждого пользователя собираются:
    - Пол (мужской/женский)
    - Дата рождения и возраст
    - Город проживания
- **Пагинация данных**: Поддержка постраничной загрузки для больших сообществ
- **Веб-парсинг**: Дополнительные возможности парсинга публичных данных со страниц ВК

## Технические детали и зависимости

- **Язык:** Python
- **Основные библиотеки:**
    - requests (для выполнения HTTP-запросов к VK API)
    - datetime (для работы с датами и вычисления возраста)
    - time (для управления паузами между запросами к API)

## Как использовать
1. **Получение данных**

Клонирование репозитория:
```
git clone git@github.com:Anastasia-0-Iva/community-vk-analysis.git
cd VK-Community-Analyzer
```

Создание виртуального окружения и установка зависимостей:

**Для Windows:**
```
python -m venv venv
.\venv\Scripts\activate
poetry install 
```

**Для Linux/macOS:**
```
python3 -m venv venv
source venv/bin/activate
poetry install 
```

2. **Настройка доступа к VK API**

- Получение access token:
- Создайте Standalone приложение в VK API
- Получите access_token через Implicit Flow
- Или используйте Service Token из настроек приложения

**Конфигурация**

В файле utils/config.py укажите ваш токен доступа и URL группы для анализа:
```
ACCESS_TOKEN = "ваш_token"
GROUP_URL = "ваш_URL"
```
